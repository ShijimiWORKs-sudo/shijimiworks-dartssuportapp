# MVP Features

DartsSupportApp MVP v0.1 で確認できる機能一覧です。

## 初期設定

- レーティング入力
- レベル自動判定
  - 初級: RT1-5
  - 中級: RT6-9
  - 上級: RT10以上
- 利用機種選択
  - DARTSLIVE
  - PHOENIX
  - 両方
- 主な悩みの複数選択
- 設定再編集

## 練習メニュー

- 24件の練習メニューDB
- レベル、機種、ゲーム種別、悩みタグで絞り込み
- 練習詳細
- 練習メニュー別の記録履歴
- お気に入り保存
- おすすめ練習表示

## 練習記録

- 記録入力
- 練習メニュー検索/選択
- 手入力メニュー名
- 写真スコア記録
  - 画像解析候補検出
  - キャリブレーションベース候補
  - 手動タップ追加
  - 候補選択後のドラッグ微調整
  - グルーピング分析と改善アドバイス
  - 実機向けステップ表示、やり直し導線、位置修正導線
- 記録一覧
- 記録詳細
- 記録編集
- 記録削除
- メニュー別記録一覧

## 分析

- 7日/30日/90日/全期間フィルタ
- 練習回数
- COUNT-UP平均
- 平均ブル数
- 平均クリケットマーク数
- ベストスコア
- スコア推移グラフ風UI
- ブル数推移グラフ風UI
- ゲーム別集計
- 調子の割合
- 改善コメント
- 次にやるべき練習

## フォーム相談

- 相談カテゴリ選択
- 深刻度選択
- 悩み入力
- 固定ロジックによる相談回答
- 関連練習メニュー表示
- 関連資料表示
- イップス関連の安全な注意文

## 相談履歴

- 相談結果のローカル保存
- 履歴一覧
- 履歴詳細
- 履歴削除
- 履歴から練習詳細/記録入力/資料詳細へ遷移

## 資料ライブラリ

- 21件の知識記事DB
- 検索
- カテゴリフィルタ
- タグフィルタ
- 関連練習あり/なしフィルタ
- 記事詳細
- 記事から相談画面へ遷移
