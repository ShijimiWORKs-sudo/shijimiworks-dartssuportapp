# QA Checklist

iPhone + Expo Go での MVP v0.1 確認用チェックリストです。

## 事前準備

- [ ] `npm install` 済み
- [ ] `npx expo start` が起動する
- [ ] iPhone とPCが同一ネットワークにある
- [ ] Expo GoでQRコードを読み込める
- [ ] Expo Goで起動確認済み

## 初期設定

- [ ] 初期設定表示確認
- [ ] `/` が表示される
- [ ] レーティングを入力できる
- [ ] レベルが自動表示される
- [ ] 利用機種を選択できる
- [ ] 主な悩みを複数選択できる
- [ ] 「はじめる」で `/home` に遷移する
- [ ] 不正入力でエラー表示される
