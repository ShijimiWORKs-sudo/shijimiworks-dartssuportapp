# QA Checklist

iPhone + Expo Go での MVP v0.1 確認用チェックリストです。

## 事前準備

- [ ] `npm install` 済み
- [ ] `npx expo start` が起動する
- [ ] iPhone とPCが同一ネットワークにある
- [ ] Expo GoでQRコードを読み込める

## 初期設定

- [ ] `/` が表示される
- [ ] レーティングを入力できる
- [ ] レベルが自動表示される
- [ ] 利用機種を選択できる
- [ ] 主な悩みを複数選択できる
- [ ] 「はじめる」で `/home` に遷移する
- [ ] 不正入力でエラー表示される

## ホーム

- [ ] ロゴとDartsSupportApp名が表示される
- [ ] rating / level / machineType が表示される
- [ ] おすすめ練習が表示される
- [ ] 分析サマリーが表示される
- [ ] 主要メニューから各画面へ遷移できる
- [ ] プロフィール未設定時に初期設定導線が表示される

## 練習メニュー

- [ ] `/practice` が表示される
- [ ] おすすめ練習と補助練習が表示される
- [ ] フィルタを切り替えられる
- [ ] お気に入り登録/解除できる
- [ ] 練習詳細へ遷移できる
- [ ] 練習詳細から記録入力へ遷移できる
- [ ] メニュー別記録一覧が空でもクラッシュしない

## 練習記録

- [ ] `/record` が表示される
- [ ] 練習メニュー選択UIを開閉できる
- [ ] 検索/フィルタで練習メニューを選べる
- [ ] 選択したメニュー名がフォームへ反映される
- [ ] 手入力でも保存できる
- [ ] 数値入力のバリデーションが動く
- [ ] 保存後 `/analysis` へ遷移する
- [ ] `/records` に保存済み記録が表示される
- [ ] 詳細、編集、削除ができる

## 分析

- [ ] `/analysis` が表示される
- [ ] 7日/30日/90日/全期間を切り替えられる
- [ ] 練習回数、平均、ベストスコアが表示される
- [ ] スコア推移とブル数推移が表示される
- [ ] 記録0件でもクラッシュしない
- [ ] おすすめ練習から詳細/記録入力へ遷移できる
- [ ] 「相談する」で `/consult` へ遷移できる

## 相談

- [ ] `/consult` が表示される
- [ ] categoryパラメータ付き遷移で初期カテゴリが反映される
- [ ] カテゴリと状態を選べる
- [ ] 悩み入力後に相談結果が表示される
- [ ] 関連練習へ遷移できる
- [ ] 関連資料へ遷移できる
- [ ] イップス関連で安全な注意文が表示される

## 相談履歴

- [ ] 相談後に履歴が保存される
- [ ] `/consult/history` に履歴一覧が表示される
- [ ] 履歴0件でもクラッシュしない
- [ ] 履歴詳細を開ける
- [ ] 履歴詳細から関連練習へ遷移できる
- [ ] 履歴詳細から記録入力へ遷移できる
- [ ] 履歴詳細から関連資料へ遷移できる
- [ ] 履歴削除の確認ダイアログが表示される
- [ ] 削除後に一覧へ戻る

## 資料検索

- [ ] `/library` が表示される
- [ ] 検索欄で絞り込みできる
- [ ] カテゴリフィルタが動く
- [ ] タグフィルタが動く
- [ ] 関連練習あり/なしフィルタが動く
- [ ] 0件メッセージが表示される
- [ ] 記事詳細を開ける
- [ ] 記事詳細から相談画面へ遷移できる

## お気に入り

- [ ] `/favorites` が表示される
- [ ] 0件でもクラッシュしない
- [ ] お気に入り練習が一覧表示される
- [ ] 詳細/記録入力へ遷移できる

## Migration

- [ ] schemaVersion 2 相当の既存データで起動してもクラッシュしない
- [ ] 既存のプロフィールが残る
- [ ] 既存の練習記録が残る
- [ ] お気に入りとフィルタ条件が残る
- [ ] `consultHistories` が空配列で補完される
